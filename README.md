# Cmpreq (Requisiciones de compra).
El paquete Cmpreq (Requisiciones de compra) de V12 es el módulo que permite la gestión integral de requisiciones de compra, incluyendo solicitudes de cotización, cuadros comparativos y generación de pedidos. Su propósito es optimizar el proceso de adquisición de bienes y servicios, asegurando trazabilidad, transparencia y eficiencia en la toma de decisiones.
